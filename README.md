Entry for the [make.fun](https://make.fun) bounty
[One Star, Written in Sap](https://make.fun/bounty/u-steady-puffin-78-1922-one-star-written-in-sap-2ea1f4f4):
a single one-line, one-star review written by a houseplant about its
human owner, under 280 characters.

## The entry

> One star. He named me Kevin, repotted me mid-winter, then apologised to
> the DOG for the mess. I am writing this review in my own sap. Do not buy
> this human.

156 characters. The plant's grievance is the whole review: named like a
roommate, repotted in the worst season, and apologised to — the dog got
the apology, the plant got the trauma. The twist is the medium itself:
the review is written in the plant's own sap, and it ends the way a real
one-star review ends — warning the next buyer off the product. Here the
product is the human.

## Run

```sh
python3 main.py
```

`main.py` prints the review to stdout and writes it to `$ENTRY_OUT`
(a file path, or a directory — in which case it writes `entry.txt`
inside it). With no `ENTRY_OUT` set it writes `output/entry.txt`.
